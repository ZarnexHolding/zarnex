## ⚠️ The attribution rule — read this before adding anything

A presents a 13-project "track record" as BuildX's own. **Nine predate BuildX's
founding** (2019, stated in both A p2 and B p2) — King Faisal Specialist
Hospital 2010–12, Almarai Project Cradle 2010–11, Almarai Project Palm 2011–13,
Alfanar Substation 2013–14, PP10 Power Station 2013–15, Almarai CPP3 2015–17,
SANGCOM 2015–18, Aldara Hospital 2016–18, Almarai Bake Roll 2017–18.

C, the newest document, resolves it explicitly:

- **p2, attribution policy:** *"Partner-company names and logos are retained so
  that experience is not presented as BuildX-only experience."*
- **p6:** *"BUILDX ENGINEERING SELECTED PROJECTS"* — exactly **four**, all 2019+.
- The pre-2019 projects reappear under partner companies — King Faisal Hospital,
  SANGCOM and Almarai Project Cradle under **Reliance** (est. 2012), p17.
- **p14:** *"They are not relabeled as BuildX projects."*
- **p36:** *"All project references remain attributed to the company profile
  from which they were sourced."*

**So the site shows only the four C p6 projects as BuildX's work.** Partner
experience — Ayaan East, Enhance Ventures, Reliance, Renovix, Greenroot — is
never presented as BuildX's. Nor is A p2's client list (MOD, SANG, Almarai,
Alfanar, ITEA, MOH, Ritz Carlton, Intercontinental): most of it traces to the
pre-2019 partner projects.

This is the client's own correction, and it matches this codebase's rule. Do not
"restore" the older track record because it looks more impressive.

## Imagery — why the page has none yet

- **B's photography is rendered and stock** — glossy towers, a generic power
  hall, composited Riyadh skylines. Not BuildX's work, and the gallery's alt
  text reads "BuildX project work". Never used.
- **Real site photos exist only on BuildX's own project pages** (A p9, p19–27;
  C p7–9) — and only as thumbnails pre-composited into collages: ~330×200px
  per shot; the largest single image is 593×429. C's copies are the same
  resolution or lower.
- The gallery displays tiles at ~475px (~950px needed on retina) and the hero
  is full-bleed. Thumbnails would read as visibly blurry next to every other
  company page.
- **So: no hero image and no gallery until originals arrive.** Both sections
  hide, per the rule. The page renders its void hero with the logo instead.
